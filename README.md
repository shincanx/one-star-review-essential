A deterministic Python program that writes one deadpan one-star review of an everyday essential — the sun, at most 160 characters — to /output/entry.txt. The complaint: the sun has no dimmer, no off switch, and one setting (too bright), and customer service is 93 million miles away.

## Run it

```sh
python3 main.py
```
